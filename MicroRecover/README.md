# MicroRecover - Sistema de Recuperação de Arquivos

Este é um sistema desenvolvido em Python para recuperar arquivos apagados em sistemas Windows.

## Funcionalidades

- Recuperação de arquivos apagados
- Suporte a diferentes tipos de arquivos
- Interface de linha de comando
- Exibição do progresso da recuperação

## Requisitos

- Python 3.8 ou superior
- Windows 10 ou superior

## Instalação

1. Clone este repositório
2. Instale as dependências:
```bash
pip install -r requirements.txt
```

## Uso

Execute o programa principal:
```bash
python main.py
```

## Aviso

Este software deve ser usado com cautela. Sempre faça backup dos seus dados importantes e use este software apenas em situações de emergência.
